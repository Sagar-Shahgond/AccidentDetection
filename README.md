# Accident Detection using Computer Vision and Machine Learning

## Project Overview
This project aims to develop a traffic accident/anomaly detection
system using computer vision and machine learning.

The project uses the AI City Challenge 2021 Track 4 dataset
for video-based analysis.

## Current Progress

- [x] Dataset inspection
- [x] Annotation parsing
- [x] Extraction of relevant source videos
- [x] Extraction of timestamp-based clips
- [x] Clip verification
- [x] YOLO object detection and ByteTrack tracking test
- [ ] Vehicle motion feature extraction
- [ ] Dataset preparation and labelling
- [ ] Accident/anomaly classification
- [ ] Model evaluation
- [ ] Final application and demonstration

## Technologies

- Python
- OpenCV
- YOLO (Ultralytics)
- ByteTrack
- Pandas
- Scikit-learn
